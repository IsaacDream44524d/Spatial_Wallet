# Spatial Wallet

**A Java-Based Digital Wallet Management System**

## About the Project

Spatial Wallet is a group software development project developed as part of the **Object-Oriented Programming (OOP)** course.

The project aims to demonstrate the practical application of Object-Oriented Programming principles through the development of a digital wallet management system. It provides a platform for users to create and manage digital wallets, perform basic wallet operations, and monitor their wallet balances.

The system is developed using Java, with a focus on applying concepts such as encapsulation, inheritance, abstraction, and polymorphism in a practical software development environment.

## Project Objectives

- Apply Object-Oriented Programming concepts in a real-world-inspired application.
- Develop a functional digital wallet management system.
- Implement user registration and wallet creation.
- Provide basic wallet operations, including deposits.
- Practise database integration and data management.
- Encourage teamwork, collaboration, and software development practices.

## Key Features

- **User Registration:** Allows users to create an account.
- **Authentication:** Provides a login interface for registered users.
- **Wallet Creation:** Allows users to create and manage their digital wallets.
- **Initial Deposit:** Enables users to fund their wallets.
- **Balance Management:** Displays available wallet balances.
- **Database Integration:** Stores and manages application data.

## Object-Oriented Programming Concepts

The project incorporates the following OOP principles:

1. **Encapsulation:** Protecting sensitive data through access modifiers and controlled access methods.
2. **Inheritance:** Promoting code reuse through relationships between classes.
3. **Abstraction:** Hiding implementation details and exposing essential functionality.
4. **Polymorphism:** Allowing objects to exhibit different behaviours through shared interfaces or inherited methods.

## Installation and Setup

### Prerequisites

Before running the application, ensure you have:

- Java Development Kit (JDK) installed.
- IntelliJ IDEA or another compatible Java IDE.
- JavaFX SDK and dependencies configured.
- Local SQLite db.
- Scene Builder (optional, for modifying FXML interfaces).

### Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project in IntelliJ IDEA.

3. Configure the required Java and JavaFX dependencies.

4. Configure the database connection.

5. Run the application using the main application class.
